WaveBrain v7: the nonlinearity pilot (validated)

This document implements the pilot proposed after v6: does a dynamically nonlinear wave medium help a linear readout solve a task that a linear readout of raw pixels cannot? It extends the v6 package without modifying any v6 module (checked by hash). Everything below (source, test output, results) comes from running the code in this document. Only numpy is required at runtime; pytest is needed for the tests.

1. Result in one paragraph

The cubic (stiffening) nonlinearity gave no measurable benefit, and in one arm it hurt. On the two-pattern same/different task, the medium without a cubic term (L) reaches 0.70 accuracy (seed 0) and 0.71 (seed 1) against 0.50 chance, while a linear readout of raw pixels is at chance (0.49). Medium Sm (beta = 0.10, amplitude-matched) is indistinguishable from L (paired difference -0.011 [-0.106, +0.081]), the equal-drive arms are too, and medium Dm (beta = 0.05, amplitude-matched) is worse (-0.183 [-0.286, -0.081]). An independent replication on seed 1 agrees on every point. Under the decision rule fixed before the final runs, the verdict is HURTS; read the interpretation in section 4 before taking that label at face value.

The more useful finding is a gap: in L the individual shapes are well remembered (pair identity 0.88, and "decode both shapes, then compare" scores 0.93), but a linear readout of the medium's response compares them with only 0.70 accuracy. The medium stores the information; it does not compute the comparison. The cubic term did not close that gap.

2. Corrections to the v6 report

Two statements in the v6 report were wrong or misleading. The pilot's calibration exposed both.

"The cubic term is about 0.3% of the linear term; the medium is nearly linear" was wrong. I compared beta*u^2 against the wrong reference using the probe amplitude. The relevant comparison is against the drive frequency squared (omega^2 = 0.09), and the fields during the write phase are of order 1. In the pilot, beta = 0.05 at the v6-level drive already reduces the write-phase field amplitude by more than half at equal drive (RMS 0.11 vs 0.26). The stiffening medium is detuned from the drive.

The beta = 0 medium is not a linear system. Reading a memory out of the medium needs parametric coupling (the hologram and the slow field modulate c^2), and writing it is a saturating product u^(n+1) * u^n. Test test_with_parametric_terms_even_beta_zero_is_nonlinear shows it, and test_without_parametric_terms_beta_zero_is_exactly_linear_and_beta_is_not shows that with those terms off, beta = 0 scales exactly linearly (ratio 2.000) and beta > 0 does not. So "L" below means "no cubic term", and the pilot tests the additional cubic nonlinearity on top of an already parametric, nonlinear memory.

3. Design

The task

Two shapes (circle, cross or ring) are written simultaneously, one above the other, into the medium. The label is 1 if they are identical and 0 otherwise.

Trial composition is a deterministic, exactly balanced function of the trial index: 60 same, 60 different; every shape equally often among the same-pairs; every ordered pair equally often among the different-pairs.

Placement jitter (+/-3 cells per pattern) comes from default_rng([seed, trial_index]) and does not depend on the medium. Every medium sees identical trials (paired design).

The task is XOR-like in pixel space: a linear readout of raw pixels identifies each shape (top-kind accuracy 1.00) but cannot compare them (same/different 0.49, permutation p = 0.65). This is checked by test_task_is_xor_like_in_pixel_space.

The media

All five media share every parameter except beta (test test_media_differ_only_in_beta). The drive multiplies the v6 amplitude of 0.02 for both writing and probing.

Why matched arms. At equal drive the stiffer media have write RMS of 0.11 (D) and 0.14 (S) against 0.26 for L: less than half the signal. Equal-drive differences would mix "nonlinearity" with "weaker memory". The matched arms hold the internal field strength fixed, so they are the primary comparison.

Diagnostic targets

Besides same/different, the same ridge readout decodes the top shape, the bottom shape and the 9-way pair identity. A fifth number, compose, decodes the pair identity linearly and then compares the two decoded shapes outside the medium. High compose with low same/different means the medium remembers but does not compare.

Decision rule (fixed before the reported runs)

Implemented as verdict() and unit-tested on synthetic inputs for every branch:

INVALID_CLIPPED: the safety clip fired anywhere (a clip is a hard nonlinearity and would contaminate the control).

TOO_HARD: no medium beats chance on same/different. Sub-case: shapes decodable (remembers, does not compare) or not (weak memory).

PROMISING: a nonlinear arm is above chance and beats L with the lower end of the paired bootstrap 95% CI above 0. Next step would be the full sweep.

HURTS: a nonlinear arm is worse than L with the upper end of the CI below 0.

NO_BENEFIT: L is above chance and no CI excludes 0.

INCONCLUSIVE: otherwise.

What was tuned, and on which data

The rule's main branches were written before any pilot run. After the first tuning run I added rule 0 and the "matched arms are primary" clause, because that run showed a clipping control and an amplitude confound (below).

All calibration (drive scale, u_limit/c2_max, calibration procedure) used tuning seed 1000 and a separate calibration seed (9999). The reported runs use seeds 0 and 1, each run once, with no code change in between (hashes checked).

The first tuning run used drive 2.0 and was invalid: the linear control hit the safety clip 21 times and scored 0.89. That number is confounded (larger drive, plus clipping) and supports no conclusion. It led to drive 1.5 (max peak field over 120 tuning trials: 1.94 against a limit of 2.4) and to rule 0.

Interpretation

No benefit from the cubic term. The upper ends of the paired intervals for the nonlinear arms against L are D +0.083, S +0.067, Sm +0.081 (seed 0) and D +0.083, S +0.106, Sm +0.083 (seed 1). A benefit larger than roughly 0.07 to 0.11 accuracy is excluded at 95%; a smaller one is not (this pilot has limited power).

"HURTS" is real for Dm but should not be generalised. Dm is worse in both seeds (-0.183 [-0.286, -0.081] and -0.144 [-0.242, -0.050]), yet Sm, which is more nonlinear, is not, and the equal-drive D is within noise. The effect is not monotonic in beta. Dm needed 2.4 times the drive to reach L's field strength, so it operates in a different regime (resonance and detuning). The supported reading is "matching amplitude by driving the beta = 0.05 medium harder degrades the memory", not "nonlinearity degrades computation".

The memory is good; the comparison is not. In L the shapes are decoded well (top 0.88, bottom 0.91, pair identity 0.88) and compose reaches 0.93, yet direct same/different is 0.70. The nonlinear arms store less (pair identity 0.46 to 0.68) and compare no better.

Seed-to-seed consistency. Same/different for L: 0.697 and 0.711; Sm: 0.686 and 0.700; Dm: 0.514 and 0.567.

What this means for the project

The pre-registered rule says not to run the beta sweep. I agree for stiffening nonlinearity. Cheap next steps that target the measured gap (0.70 direct vs 0.93 compose) are:

A nonlinear readout on the datasets that already exist (kernel ridge, or quadratic features). If it closes the gap, the project is "plastic memory plus nonlinear readout", and no new simulation is needed.

A different kind of dynamical nonlinearity (saturating, for example sine-Gordon) instead of stiffening, which mainly detunes the drive.

A sequential-write variant of the task, where the first pattern's hologram modulates how the second one is written.

7. Limitations

Power. With 120 trials the paired 95% intervals are about +/-0.10 wide. The pilot detects harm or benefit of roughly 0.1 or more, not smaller effects. "No evidence of benefit" is not "no benefit".

Two seeds, one configuration. Both reported runs use the same sensors, noise (0.015), pattern size and delay. Two seeds support replication of the main pattern but not a variance estimate across configurations.

One kind of nonlinearity. Only the stiffening cubic term was tested. A saturating nonlinearity may behave differently.

Arm Dm is not understood. Its poor performance is attributed to operating at 2.4 times the drive (resonance and detuning), but this was not tested directly.

L is not linear (section 2); the pilot says nothing about nonlinearity in the memory itself, which is present in every arm.

Calibration targets write-phase RMS only. Other matching choices (hologram strength, probe response size) could change the picture.

Synthetic task. Three simple shapes, simulated sensor noise, simultaneous writing only.

Verdict label. "HURTS" is the literal output of the pre-registered rule, triggered by one arm of two. The interpretation in section 4 is more careful than the label.

"""Small statistical helpers for paired comparisons between models.""" from __future__ import annotations import numpy as np def paired_bootstrap_diff(a, b, n_boot: int = 4000, seed: int = 0, level: float = 0.95) -> dict: """Bootstrap CI for mean(a) - mean(b) on the SAME samples (paired resampling). ``a`` and ``b`` are per-sample scores (e.g. correctness in [0, 1]). Resampling the sample indices jointly keeps the pairing, which is far more powerful than comparing two marginal confidence intervals. """ a, b = np.asarray(a, float), np.asarray(b, float) if a.shape != b.shape or a.ndim != 1 or len(a) < 2: raise ValueError("a and b must be 1-D arrays of equal length >= 2") if not (0.0 < level < 1.0): raise ValueError("level must lie in (0, 1)") rng = np.random.default_rng(seed) idx = rng.integers(0, len(a), size=(n_boot, len(a))) diffs = (a[idx] - b[idx]).mean(axis=1) alpha = 1.0 - level lo, hi = np.quantile(diffs, [alpha / 2.0, 1.0 - alpha / 2.0]) return {"diff": float(a.mean() - b.mean()), "lo": float(lo), "hi": float(hi)}

wavebrain/pilot.py

"""Nonlinearity pilot: ``python -m wavebrain.pilot [--quick]``. Question -------- Does a *dynamically* nonlinear medium (cubic coefficient beta) help a linear readout solve the two-pattern SAME / DIFFERENT task, compared with an otherwise identical linear medium (beta = 0)? Media (identical in everything except ``beta``; same drive, same trials) ------------------------------------------------------------------------ L beta = 0 no cubic term D beta = 0.05 the v6 default, equal drive to L S beta = 0.10 strongly nonlinear, equal drive to L Dm beta = 0.05 drive calibrated so the write-phase RMS field equals L's Sm beta = 0.10 same, for beta = 0.10 Why the matched arms: a stiffening medium is detuned from the drive, so at equal drive its fields (and hologram) are less than half as strong as L's. Equal-drive differences would mix "nonlinearity" with "weaker signal". The matched arms are the primary test. Caveat that shapes the interpretation: L is NOT a linear system. Reading the memory out requires parametric coupling (the hologram and the slow field modulate c^2), and writing it is a saturating product u^{n+1} u^n. What differs between L and D/S is only the additional *cubic* nonlinearity of the wave dynamics. The decision rule (``verdict``) was fixed BEFORE the final run; see its docstring. cols += [hi_c] * n_per_side elif side == "left": rows += along_r.tolist(); cols += [lo_c] * n_per_side elif side == "top": rows += [lo_r] * n_per_side; cols += along_c.tolist() elif side == "bottom": rows += [hi_r] * n_per_side; cols += along_c.tolist() else: raise ValueError(f"unknown side '{side}'") arr = SensorArray(np.array(rows), np.array(cols)) arr.validate(cfg) return arr def probe_geometry(cfg: MediumConfig, inset: int = 3) -> tuple[int, int, int]: """(column, row_start, row_stop) of the vertical probe line source (2 columns thick).""" col = cfg.sponge_width + inset return col, cfg.sponge_width + inset, cfg.ny - cfg.sponge_width - inset def arrival_steps(cfg: MediumConfig, sensors: SensorArray, probe_col: int, probe_rows: tuple[int, int], slowest: bool = False) -> np.ndarray: """Straight-line travel time (steps) from the probe line to every sensor.""" r0, r1 = probe_rows dy = np.maximum(np.maximum(r0 - sensors.rows, sensors.rows - (r1 - 1)), 0) dx = np.abs(sensors.cols - probe_col) dist = np.hypot(dx, dy) c = np.sqrt(cfg.c2_min) if slowest else cfg.c_fast return dist / c def check_timing(cfg: MediumConfig, sensors: SensorArray, probe_col: int, probe_rows: tuple[int, int], readout_steps: int, burst_steps: float, margin: float = 1.2) -> dict: """Raise ValueError unless the whole probe burst can reach every sensor in the window. ``margin`` (> 1) allows for numerical group-velocity dispersion: measured arrivals of the narrow-band burst are ~10-15% later than distance / c_fast. """ arr = arrival_steps(cfg, sensors, probe_col, probe_rows) needed = float(arr.max() * margin + burst_steps) if needed > readout_steps: raise ValueError( f"readout window too short: the probe needs ~{needed:.0f} steps to reach the farthest " f"sensor (+burst), but only {readout_steps} steps are recorded" ) return {"max_arrival": float(arr.max()), "min_arrival": float(arr.min()), "needed_steps": needed, "window": readout_steps} 

wavebrain/medium.py

"""2-D nonlinear wave medium with a plastic "hologram" memory. Scheme (dt = dx = 1), for the fast field u with gamma = damping: u^{n+1} = [ 2u^n - (1 - g/2) u^{n-1} + c2 * lap(u^n) - beta * (u^n)^3 + F^n ] / (1 + g/2) with g = damping + gamma_layer(x) * c2 is clipped to [c2_min, c2_max] so it can never go negative or exceed the explicit-scheme limit (original code: c2 ranged from -0.44 to 1.06). * The cubic term is *restoring* (beta >= 0). The original term had a constant +18.5 outward push for |u| > ~25, which made a single blob invade the whole domain as a uniform plateau. * Sources are forcing terms inside the update, not state overwrites. * The outer ``sponge_width`` cells form a *viscous* absorbing layer: a smoothly ramped friction coefficient gamma(x) inside the update. (The original used a multiplicative sponge, which acts partly as a spring to zero: it reflected 15-26% of the energy at low frequency and got *worse* when made stronger.) This is a damping layer, not a true PML. Sensors must stay outside it. """ from __future__ import annotations import copy import numpy as np from .config import MediumConfig from .sensors import SensorArray from .sources import Source class WaveMedium: def __init__(self, cfg: MediumConfig | None = None): self.cfg = cfg or MediumConfig() c = self.cfg dt = np.dtype(c.dtype) shape = (c.ny, c.nx) self._f = np.zeros((3,) + shape, dtype=dt) # fast field ring buffer self._s = np.zeros((3,) + shape, dtype=dt) # slow field ring buffer self._k = 0 # prev=k%3, cur=(k+1)%3, next=(k+2)%3 self.H = np.zeros(shape, dtype=dt) # hologram self.t = 0 # absolute step counter self.plastic = False # hologram write enabled? self.sources: list[Source] = [] self.clip_events = 0 # Viscous absorbing layer: total friction = bulk damping + layer profile gamma_layer(x). layer = self._build_layer() self.gamma_map = (c.damping + layer).astype(dt) self.gamma_map_slow = (c.damping_slow + layer).astype(dt) self._a, self._b = 1.0 - 0.5 * self.gamma_map, 1.0 + 0.5 * self.gamma_map self._a_s, self._b_s = 1.0 - 0.5 * self.gamma_map_slow, 1.0 + 0.5 * self.gamma_map_slow # ----------------------------------------------------------- state access @property def u(self) -> np.ndarray: """Current fast field (state n).""" return self._f[(self._k + 1) % 3] @property def u_prev(self) -> np.ndarray: return self._f[self._k % 3] @property def s(self) -> np.ndarray: """Current slow field.""" return self._s[(self._k + 1) % 3] def clone(self) -> "WaveMedium": """Independent deep copy (arrays, sources, hologram, clock).""" return copy.deepcopy(self) # -------------------------------------------------------------- utilities def _build_layer(self) -> np.ndarray: """Friction coefficient gamma_layer(y, x): 0 inside, ramps up (power law) to ``sponge_strength`` at the outer edge over ``sponge_width`` cells.""" c = self.cfg w = c.sponge_width def profile(n: int) -> np.ndarray: sig = np.zeros(n) if w > 0 and c.sponge_strength > 0: ramp = c.sponge_strength * ((w - np.arange(w)) / w) ** c.sponge_power sig[:w] = ramp sig[-w:] = np.maximum(sig[-w:], ramp[::-1]) return sig sy, sx = profile(c.ny), profile(c.nx) return np.maximum(sy[:, None], sx[None, :]) def add_source(self, src: Source) -> Source: src.check_inside(self.cfg.ny, self.cfg.nx) self.sources.append(src) return src def remove_source(self, src: Source) -> None: self.sources = [s for s in self.sources if s is not src] def _c2(self, s_cur: np.ndarray) -> np.ndarray: c = self.cfg mod = 1.0 + c.slow_mod * s_cur[1:-1, 1:-1] + c.holo_mod * self.H[1:-1, 1:-1] return np.clip(c.c2_nominal * mod, c.c2_min, c.c2_max) # ------------------------------------------------------------------- step def step(self) -> None: c = self.cfg ip, ic, inx = self._k % 3, (self._k + 1) % 3, (self._k + 2) % 3 fp, fc, fn = self._f[ip], self._f[ic], self._f[inx] sp, sc, sn = self._s[ip], self._s[ic], self._s[inx] I = (slice(1, -1), slice(1, -1)) lap_f = fc[:-2, 1:-1] + fc[2:, 1:-1] + fc[1:-1, :-2] + fc[1:-1, 2:] - 4.0 * fc[I] lap_s = sc[:-2, 1:-1] + sc[2:, 1:-1] + sc[1:-1, :-2] + sc[1:-1, 2:] - 4.0 * sc[I] # fast field cur = fc[I] fn[I] = (2.0 * cur - self._a[I] * fp[I] + self._c2(sc) * lap_f - c.beta * (cur * cur * cur)) / self._b[I] # forcing for src in self.sources: amp = src.envelope(self.t) if amp != 0.0: region = (slice(src.y0, src.y1), slice(src.x0, src.x1)) fn[region] += (src.profile * amp / self._b[region]).astype(fn.dtype) # slow field (driven by the fast field's curvature) sn[I] = (2.0 * sc[I] - self._a_s[I] * sp[I] + (c.c_slow ** 2) * lap_s + c.slow_drive * lap_f) / self._b_s[I] # safety net: must stay at zero in nominal operation (tests assert this) m = float(np.abs(fn).max()) if not np.isfinite(m): raise FloatingPointError(f"non-finite field at step {self.t}") if m > c.u_limit: self.clip_events += 1 np.clip(fn, -c.u_limit, c.u_limit, out=fn) # hologram: leaky, saturating accumulation of u^{n+1} * u^n / |u| if self.plastic: prod = fn * fc norm = np.sqrt(fn * fn + fc * fc + 1e-8) h = c.holo_decay * self.H + c.holo_rate * prod / norm self.H = (c.holo_sat * np.tanh(h / c.holo_sat)).astype(self.H.dtype) else: self.H *= c.holo_decay self.t += 1 self._k += 1 def run(self, n: int, sensors: SensorArray | None = None) -> np.ndarray | None: """Advance ``n`` steps; if ``sensors`` is given return the (n_sensors, n) record.""" if sensors is None: for _ in range(n): self.step() return None sensors.validate(self.cfg) out = np.empty((len(sensors), n), dtype=self.u.dtype) for i in range(n): self.step() out[:, i] = self.u[sensors.rows, sensors.cols] return out # ------------------------------------------------------------ diagnostics def staggered_energy(self) -> float: """Exactly conserved energy of the *linear, homogeneous, undamped* scheme. E = 1/2 |u^{n+1} - u^n|^2 - 1/2 c^2 <u^{n+1}, lap(u^n)>. Only meaningful when gamma = beta = 0, mods = 0, no sponge, no sources. """ cur, prev = self.u.astype(float), self.u_prev.astype(float) lap_prev = (prev[:-2, 1:-1] + prev[2:, 1:-1] + prev[1:-1, :-2] + prev[1:-1, 2:] - 4.0 * prev[1:-1, 1:-1]) kinetic = 0.5 * np.sum((cur - prev) ** 2) potential = -0.5 * self.cfg.c2_nominal * np.sum(cur[1:-1, 1:-1] * lap_prev) return float(kinetic + potential) def stability_report(self) -> dict: c = self.cfg c2 = self._c2(self.s) umax = float(np.abs(self.u).max()) return { "finite": bool(np.isfinite(self.u).all() and np.isfinite(self.s).all()), "max_abs_u": umax, "c2_min_now": float(c2.min()), "c2_max_now": float(c2.max()), "stiffness_bound": 8.0 * float(c2.max()) + 3.0 * c.beta * umax ** 2, "clip_events": self.clip_events, "config_stability_number": c.stability_number, } 

wavebrain/classifier.py

"""Linear readout: ridge classifier, stratified CV, permutation test, Wilson CI. Pure numpy. A linear readout is the standard choice for reservoir computing and, unlike the original 57k-parameter MLP trained on a handful of samples, cannot silently memorise a tiny dataset (alpha is chosen by closed-form leave-one-out error). """ from __future__ import annotations import numpy as np class RidgeClassifier: """One-vs-rest ridge regression on +/-1 targets (dual form, LOO-selected alpha).""" def __init__(self, alphas=None, scale: str = "global"): self.alphas = np.logspace(-3, 5, 17) if alphas is None else np.asarray(alphas, float) if scale not in ("global", "feature"): raise ValueError("scale must be 'global' or 'feature'") self.scale = scale def fit(self, X, y) -> "RidgeClassifier": X = np.asarray(X, dtype=float) y = np.asarray(y) n = len(y) if X.ndim != 2 or X.shape[0] != n: raise ValueError("X must be 2-D with one row per label") self.classes_ = np.unique(y) if len(self.classes_) < 2 or n < 4: raise ValueError("need >= 2 classes and >= 4 samples") idx = np.searchsorted(self.classes_, y) self.mean_ = X.mean(axis=0) Xc = X - self.mean_ self.scale_ = (Xc.std(axis=0) + 1e-12) if self.scale == "feature" else (Xc.std() + 1e-12) Xs = Xc / self.scale_ Y = -np.ones((n, len(self.classes_))) Y[np.arange(n), idx] = 1.0 self.y_mean_ = Y.mean(axis=0) Yc = Y - self.y_mean_ evals, V = np.linalg.eigh(Xs @ Xs.T) evals = np.clip(evals, 0.0, None) VtY = V.T @ Yc best_err, best_alpha = np.inf, self.alphas[0] self.loo_errors_ = [] for a in self.alphas: d = evals / (evals + a) fitted = V @ (d[:, None] * VtY) h = (V ** 2) @ d loo = (Yc - fitted) / np.maximum(1.0 - h, 1e-8)[:, None] err = float(np.mean(loo ** 2)) self.loo_errors_.append(err) if err < best_err: best_err, best_alpha = err, a self.alpha_ = float(best_alpha) dual = V @ (VtY / (evals + self.alpha_)[:, None]) self.coef_ = Xs.T @ dual return self def decision_function(self, X) -> np.ndarray: Xs = (np.asarray(X, dtype=float) - self.mean_) / self.scale_ return Xs @ self.coef_ + self.y_mean_ def predict(self, X) -> np.ndarray: return self.classes_[np.argmax(self.decision_function(X), axis=1)] def score(self, X, y) -> float: return float(np.mean(self.predict(X) == np.asarray(y))) def stratified_folds(y, k: int = 5, seed: int = 0) -> list[tuple[np.ndarray, np.ndarray]]: """(train_idx, test_idx) pairs; every sample is tested exactly once.""" y = np.asarray(y) rng = np.random.default_rng(seed) parts: list[list[np.ndarray]] = [[] for _ in range(k)] for cls in np.unique(y): members = rng.permutation(np.flatnonzero(y == cls)) for i, chunk in enumerate(np.array_split(members, k)): parts[i].append(chunk) tests = [np.concatenate(p) for p in parts] everything = np.arange(len(y)) return [(np.setdiff1d(everything, t), t) for t in tests] def cross_val_predict(X, y, k: int = 5, seed: int = 0, make=RidgeClassifier) -> np.ndarray: X, y = np.asarray(X, float), np.asarray(y) pred = np.empty_like(y) for tr, te in stratified_folds(y, k, seed): pred[te] = make().fit(X[tr], y[tr]).predict(X[te]) return pred def cross_val_accuracy(X, y, k: int = 5, seed: int = 0, make=RidgeClassifier) -> float: return float(np.mean(cross_val_predict(X, y, k, seed, make) == np.asarray(y))) def wilson_interval(successes: int, n: int, z: float = 1.96) -> tuple[float, float]: """95% Wilson score interval for a binomial proportion.""" if n <= 0: raise ValueError("n must be positive") p = successes / n denom = 1.0 + z * z / n centre = (p + z * z / (2 * n)) / denom half = z * np.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / denom return float(max(0.0, centre - half)), float(min(1.0, centre + half)) def permutation_test(X, y, observed: float, n_perm: int = 100, k: int = 5, seed: int = 0, make=RidgeClassifier) -> tuple[float, np.ndarray]: """p-value of ``observed`` CV accuracy under shuffled labels, plus the null samples.""" X, y = np.asarray(X, float), np.asarray(y) rng = np.random.default_rng(seed) null = np.array([cross_val_accuracy(X, rng.permutation(y), k, seed + 1 + i, make) for i in range(n_perm)]) p = (1.0 + float(np.sum(null >= observed - 1e-12))) / (n_perm + 1.0) return p, null def class_separability(X, y) -> float: """Mean between-centroid distance / RMS within-class distance (> 1 means separable).""" X, y = np.asarray(X, float), np.asarray(y) classes = np.unique(y) cents = np.stack([X[y == c].mean(axis=0) for c in classes]) between = np.mean([np.linalg.norm(cents[i] - cents[j]) for i in range(len(classes)) for j in range(i + 1, len(classes))]) resid = X - cents[np.searchsorted(classes, y)] within = np.sqrt(np.mean(np.sum(resid ** 2, axis=1))) return float(between / within) if within > 0 else float("inf") 

wavebrain/experiment.py

"""Pattern-memory experiment: write -> delay -> probe (with paired baseline) -> read. Protocol per trial ------------------ 1. WRITE a pattern (circle/cross/ring, equal energy, random +/-jitter placement) is driven into the medium for ``write_steps`` while the hologram is plastic. 2. DELAY sources off, plasticity off. Waves radiate into the absorber; only the hologram (and a little slow-field activity) still "remembers". 3. PROBE the medium is cloned twice. Clone A receives a probe burst, clone B does not. The feature is the paired difference A - B at interior sensors, which removes ring-down and uncontrolled background activity (baseline subtraction). 4. READ additive sensor noise, block-average downsampling, linear readout. """ from __future__ import annotations import time from dataclasses import dataclass import numpy as np from .config import ExperimentConfig from .medium import WaveMedium from .sensors import SensorArray, check_timing, probe_geometry, ring_layout from .sources import (GaussianBurst, Gated, Sine, Source, line_profile, make_pacemakers, make_pattern) RAW_CANVAS = 40 # size of the canvas used for the raw-pixel reference baseline @dataclass class Dataset: cfg: ExperimentConfig responses: np.ndarray # (N, n_sensors, readout_steps) clean paired responses y: np.ndarray # (N,) integer class ids raw: np.ndarray # (N, RAW_CANVAS**2) raw pattern pixels (reference baseline) stats: dict def features(self, noise_std: float | None = None, seed: int = 12345) -> np.ndarray: """Add sensor noise to raw samples, block-average in time, flatten.""" std = self.cfg.sensor_noise if noise_std is None else noise_std r = self.responses.astype(float) if std > 0: r = r + np.random.default_rng(seed).normal(0.0, std, r.shape) ds = self.cfg.downsample t = (r.shape[2] // ds) * ds r = r[:, :, :t].reshape(r.shape[0], r.shape[1], t // ds, ds).mean(axis=3) return r.reshape(r.shape[0], -1) def noise_per_feature(self, noise_std: float | None = None) -> float: """Std of the sensor noise on one (block-averaged) feature.""" std = self.cfg.sensor_noise if noise_std is None else noise_std return float(std / np.sqrt(self.cfg.downsample)) def detectability(self, noise_std: float | None = None) -> float: """Matched-filter d' between classes: mean pairwise centroid distance / noise std. This is the step-1 sanity statistic. It is computed on noise-free features and compared against the sensor-noise floor, so it answers "does the pattern leave a trace above the sensor noise?". d' near 0 means no (the original code's readout carried only ~1e-4 noise regardless of pattern); d' >> 1 means yes. It ignores placement jitter, so it is an optimistic upper bound on classifiability. """ X = self.features(0.0) classes = np.unique(self.y) cents = np.stack([X[self.y == c].mean(axis=0) for c in classes]) dists = [np.linalg.norm(cents[i] - cents[j]) for i in range(len(classes)) for j in range(i + 1, len(classes))] return float(np.mean(dists) / self.noise_per_feature(noise_std)) def build_sensors(cfg: ExperimentConfig) -> SensorArray: return ring_layout(cfg.medium, cfg.n_sensors_per_side, sides=cfg.sensor_sides) def validate_experiment(cfg: ExperimentConfig) -> dict: """Static checks: sensors are in the interior and the probe can reach them in time.""" sensors = build_sensors(cfg) col, r0, r1 = probe_geometry(cfg.medium) info = check_timing(cfg.medium, sensors, col, (r0, r1), cfg.readout_steps, burst_steps=6.0 * cfg.probe_tau) half = cfg.pattern_size // 2 + cfg.jitter + 2 m = cfg.medium if (m.ny // 2 - half < m.sponge_width) or (m.nx // 2 - half < m.sponge_width): raise ValueError("pattern (with jitter) would overlap the absorbing layer") return info def _probe_source(cfg: ExperimentConfig, t_now: int) -> Source: col, r0, r1 = probe_geometry(cfg.medium) env = GaussianBurst(cfg.probe_amp, cfg.probe_omega, t0=t_now + 3.0 * cfg.probe_tau, tau=cfg.probe_tau) return Source(line_profile(r1 - r0, 2), r0, col, env, "probe") def simulate_trial(cfg: ExperimentConfig, kind: str, rng: np.random.Generator, sensors: SensorArray) -> tuple[np.ndarray, np.ndarray, dict]: m = cfg.medium sim = WaveMedium(m) if cfg.background_pacemakers > 0: for src in make_pacemakers(cfg.background_pacemakers, (m.ny, m.nx), m.sponge_width + 2, rng, cfg.background_amp): sim.add_source(src) dy, dx = (int(v) for v in rng.integers(-cfg.jitter, cfg.jitter + 1, size=2)) pat = make_pattern(kind, cfg.pattern_size) y0 = m.ny // 2 - cfg.pattern_size // 2 + dy x0 = m.nx // 2 - cfg.pattern_size // 2 + dx # 1. write write = sim.add_source(Source(pat, y0, x0, Gated(Sine(cfg.write_amp, cfg.write_omega), 0, cfg.write_steps), "write")) sim.plastic = cfg.use_hologram sim.run(cfg.write_steps) sim.remove_source(write) sim.plastic = False h_after_write = float(np.abs(sim.H).max()) # 2. delay sim.run(cfg.delay_steps) # 3. paired probe / baseline a, b = sim.clone(), sim.clone() a.add_source(_probe_source(cfg, a.t)) resp = a.run(cfg.readout_steps, sensors).astype(float) - b.run(cfg.readout_steps, sensors).astype(float) canvas = np.zeros((RAW_CANVAS, RAW_CANVAS)) ry, rx = RAW_CANVAS // 2 - cfg.pattern_size // 2 + dy, RAW_CANVAS // 2 - cfg.pattern_size // 2 + dx canvas[ry:ry + cfg.pattern_size, rx:rx + cfg.pattern_size] = pat info = {"hologram_max": h_after_write, "clip_events": a.clip_events + b.clip_events + sim.clip_events, "max_abs_u": max(float(np.abs(a.u).max()), float(np.abs(sim.u).max()))} return resp, canvas.ravel(), info def build_dataset(cfg: ExperimentConfig, verbose: bool = False) -> Dataset: validate_experiment(cfg) sensors = build_sensors(cfg) n_cls = len(cfg.classes) order = [(i, c) for i in range(cfg.trials_per_class) for c in range(n_cls)] resp, raw, ys = [], [], [] clip, hmax = 0, [] t0 = time.time() for n, (i, c) in enumerate(order): rng = np.random.default_rng([cfg.seed, c, i]) # reproducible, order-independent r, canvas, info = simulate_trial(cfg, cfg.classes[c], rng, sensors) resp.append(r); raw.append(canvas); ys.append(c) clip += info["clip_events"]; hmax.append(info["hologram_max"]) if verbose and (n + 1) % 15 == 0: print(f" trial {n + 1}/{len(order)} ({time.time() - t0:.0f}s)", flush=True) stats = {"clip_events": int(clip), "hologram_max_mean": float(np.mean(hmax)), "seconds": time.time() - t0, "response_rms": float(np.sqrt(np.mean(np.square(resp))))} return Dataset(cfg, np.stack(resp), np.array(ys), np.stack(raw), stats)
